# 核心能力

## Agent 工作闭环

深蓝可以读取和搜索项目、编辑文件、执行命令、调用联网工具，并在一次会话中持续完成多步骤任务。Core 与终端 UI 解耦，日常使用由 Ink 全屏 TUI 提供流式反馈。

## 记忆与技能

- Auto Memory 保存值得跨会话复用的信息。
- 坑记忆在危险或易错动作发生前主动提醒。
- Skill 将稳定流程封装为按需加载的操作说明和资源。
- MCP 接入外部工具与数据源，密钥可通过环境变量引用。

## 长任务与上下文

Plan Mode 用于只读分析和实施规划；目标模式为长任务提供更高步骤上限。上下文压缩、工具结果外置和后台探索 Agent 帮助控制长会话成本与噪声。

## 成本与模型路由

内置 cost-first 与 quality-first 路由、会话和单日成本护栏、调用用量统计。用户始终使用自己的模型账户，深蓝不托管模型密钥或代收模型费用。
