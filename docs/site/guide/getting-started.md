# 快速开始

## 发布状态

公开 npm 版本仍在准备中。正式开放后，安装、升级与版本验证命令会统一发布在本页；开放前不提供私有 registry 凭据或私有仓库访问方式。

## 使用前准备

- Node.js 22 或更高版本。
- 至少一个受支持模型的 API Key。
- 一个需要读取、分析或修改的本地工作目录。

## 首次运行流程

1. 启动 `shenlan`，进入首次配置向导。
2. 选择模型提供方并粘贴自己的 API Key。
3. 完成连通性测试后，在目标项目目录中输入任务。
4. 使用 `Shift+Tab` 切换权限模式；写文件和执行命令默认需要确认。

深蓝支持交互会话、单次 headless 任务、会话恢复和长任务目标模式。公开版本开放时，本页将补充可直接复制的安装命令。
