# 安全与本地数据

## 数据边界

会话、配置、记忆和审计记录默认保存在本机。深蓝没有账号系统或云端会话服务；发送给模型提供方的数据仍受用户所选提供方的服务条款约束。

## 权限控制

- 默认模式下，读操作自动放行，写操作和 Shell 命令需要确认。
- Plan Mode 强制只读，优先级高于其他权限模式。
- 高危动作由独立安全网拦截，不因权限模式改变而失效。
- write/edit 操作创建可恢复快照，删除操作优先进入回收站。

## 密钥与成本

API Key 可保存在受限权限的本地配置中，也可以只通过环境变量提供。提交安全扫描会拦截常见凭据；成本护栏在调用模型前检查会话和单日预算。

公开 npm 发布前会单独审计 tarball。发现安全漏洞请按 [SECURITY.md](https://github.com/liam61-hub/shenlan/blob/master/SECURITY.md) 私下报告。
